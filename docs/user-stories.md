# Client portal user stories

- As a signed-in client, I can read current announcements by category in my preferred language.
- As a client, I can see only my own reminders and mark or dismiss them without affecting another client.
- As staff, I can create a renewal reminder with a date and send document-request / quotation alerts.
- As a client, I can delete my own **draft** with a confirmation step, but never submitted work.
- As a client, I can delete a file while my own application remains a draft.
- As a client, I can request account deletion for staff review, without immediate destruction.
- As a visitor, I can navigate common questions through a scripted, non-AI help assistant.
- As a client, I can supply optional fiscal details and request a manually issued invoice.
- As an administrator, I can inspect the dry-run plan and backup state before approving migration.
- As an operator, I can restore a clean SQLite snapshot and private file archives if an authorized maintenance operation fails.
