**Status: review candidate only. No production deployment or account deletion.**

## Production compatibility

The previously verified live DB schema ends at `portal.0011_contact_leads`. The repository also includes `portal.0012_pricing_research`, which is expressly **on hold**.

Operational models live in the independent `galiel_ops` app with migration `galiel_ops.0001_initial`, dependent on `portal.0011_contact_leads`. Do **not** execute `migrate` without an app target; it could inadvertently apply the pending pricing migration. Review:

```bash
python manage.py showmigrations portal galiel_ops
python manage.py migrate galiel_ops --plan
python manage.py sqlmigrate galiel_ops 0001
python manage.py makemigrations --check --dry-run
```

Block apply if plan includes `portal.0012_pricing_research`, if any unexpected schema changes appear, or if live production models require missing columns. DB backup and restore drill required first. After approval, the only data migration is `python manage.py migrate galiel_ops 0001`; never auto-run the entire migration graph.

## Routing and server configuration (review individually)

New Django routes require a reviewed change to the production `.htaccess` because Apache currently rewrites an explicit allowlist, not all URLs. This patch **cannot** be safely autogenerated without inspecting the actual active `.htaccess` rewrite targets/conditions.

Paths needing FastCGI:
- `/updates/`
- `/alerts/`, `/alerts/count/`, `/alerts/{id}/read/`, `/alerts/{id}/dismiss/`
- `/help/options/`, `/help/services/`, `/help/requirements/{id}/`, `/help/my-processes/`
- `/profile/fiscal/`, `/profile/request-deletion/`
- `/services/applications/{id}/delete-draft/`, `/services/applications/{id}/delete-draft-file/{docid}/`, `/services/applications/{id}/request-invoice/`

Add Django `galiel_ops.apps.GalielOpsConfig` to `INSTALLED_APPS` by a **minimal diff**, preserving production environment loader, SECRET_KEY, DEBUG, media paths and SMTP. Add `include('galiel_ops.urls')` before `portal.urls`, preserving all routes.

## Security review

1. HSTS: after verifying TLS everywhere, propose `Strict-Transport-Security: max-age=300` on HTTPS responses only; first verify redirects, zero mixed content, and no unintended subdomain effects. Do not enable `includeSubDomains` or preload without separate approval. Inspect `.htaccess` and make a minimal, reviewed patch. Confirm via `curl -sSI https://galiel.wardenclyffefirm.com/login/`. Roll back by removing that exact HSTS header stanza (previous HSTS remains cached for max-age).
2. GitHub: in repository **Settings → Security → Code security and analysis / Secret Protection**, enable secret scanning and push protection. This requires a repository administrator; the current connector exposes no action to change these settings. After enabling, verify both show Enabled.
3. Test account: run `python manage.py galiel_retire_test_account --email 'EXACT_EMAIL'` before any removal. The command refuses to delete staff or any account with associated business records. Deletion requires a fresh verified DB backup, exact email confirmation, and `APPROVE_GALIEL_TEST_ACCOUNT_REMOVAL=YES`. Execute separately from the website release, not as a migration.
4. WordPress: locate the exact `wp-config.php` file and verify owner, group, PHP execution user, and current permissions without printing secret contents. If account-owned PHP can still read it at `0600`, change only that file to `chmod 600`; otherwise assess `0640`. Check the WordPress site immediately afterward. Never recursively chmod the project.

## Acceptance checks

- `python manage.py test portal` using an isolated test database and temporary upload root; review failures (none silently skipped).
- Check migration plan and exact SQL; no pricing migration, fee import or Stripe change.
- Anonymous clients cannot access private pages and private document downloads.
- Two normal client accounts cannot access, modify or infer each other's alerts, applications, uploads, fiscal details, or invoice requests.
- Staff can create/edit/delete announcements; publication and expiry filters work in EN/ES/FR.
- Change a test application's status to missing documents / quoted: reminder created once, email delivered, unread counter increments.
- Draft deletion requires exact confirmation; paid/submitted cases cannot be deleted.
- Optional invoice request posts and alerts staff, but never generates an invoice or initiates payment.
- Scripted helper offers the four deterministic choices in EN/ES/FR; WhatsApp link remains intentionally unavailable pending approved number.
- Test backup restore on a private copy before enabling unattended nightly jobs.
- Smoke-test all new URLs against **Apache**, not just Django's URL resolver.
- Verify static assets are HTTP 200, byte identical, and no Python, .env, SQLite, or .git paths are accessible.

## Rollback

Back up `db.sqlite3` via SQLite's backup API and archive existing private uploads before any migration. Keep file-level copies of settings, URLs, FastCGI, .htaccess, templates and CSS. Automatic code rollback may restore prior files after a failed self-test; schema rollback is **not** automatic because new client writes may have occurred. Reverting `galiel_ops` tables or restoring an earlier DB snapshot requires a separate, supervised maintenance window with confirmed data retention.
