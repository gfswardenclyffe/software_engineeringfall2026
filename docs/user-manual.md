# Galiel client and staff user manual

## Clients
1. Log in and open **News & updates** to read published announcements; filter by category.
2. Open the bell icon to view reminders. Mark an alert read or dismiss it using its own form.
3. On **My processes**, use **Delete draft** only on drafts you created. Confirm the reference number; submitted work is protected.
4. On a draft, remove an uploaded document with the Delete button. Other clients cannot access or remove your files.
5. Under **My profile**, optionally enter fiscal details and request account deletion for staff review.
6. Within a process, select **Necesito factura**. Staff will process the request manually.
7. Use the help bubble for services, required documents, your own process status, or contacting the team.

## Staff
- Create and edit localized announcements in Django Admin.
- Create renewal reminders with a date; check automated document and quotation reminders.
- Review account-deletion requests before any account maintenance.
- Review invoice requests; issue any fiscal invoice externally using the official tax portal.
- Verify cron email logs and daily backup archives.

## Security
Never use links to guess another client's case ID. Contact support if an unexpected permission error appears. HTTPS and sessions are required for private views.
